# Daulet Design портфолиосы

Қазақ және орыс тілдеріндегі статикалық портфолио. Басты бет — index.html. Құрастыру немесе тәуелділіктер орнату қажет емес.

## GitHub-қа жүктеу

1. Архивті ашыңыз.
2. GitHub репозиторийінің түбіріне index.html, portfolio-assets қалтасын, .nojekyll және README.md файлдарын жүктеңіз.
3. Өзгерістерді сақтап, репозиторийдің GitHub Pages баптауларында жариялау көзі ретінде main тармағының түбірін таңдаңыз.
4. Жариялау аяқталған соң GitHub Pages берген сілтемені ашыңыз.

index.html файлы репозиторий түбірінде, portfolio-assets қалтасы оның жанында орналасуы керек. Суреттердің атауларын және қалта құрылымын сақтаңыз.

## Өтінім формасы

Форма index.html ішіндегі orderEndpoint мекенжайында жарияланған Google Apps Script қызметіне POST сұрауын жібереді. Google Sheets-ке жазылуы осы қаптаманы дайындау кезінде тексерілмеді. Жариялаған соң форманың өтінімді қабылдайтынын тексеріңіз.

## Құрамы

index.html ішінде бет құрылымы, стильдер және JavaScript орналасқан. portfolio-assets қалтасында бетте қолданылатын суреттер бар.
